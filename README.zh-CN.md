# xadmin

> 本项目的灵感来自于[streamlit](https://github.com/streamlit/streamlit)

## 特性

- 支持Ant Design、Element Plus和Arco Design等主流的企业级组件库
- 丰富的内置组件，且支持第三方组件扩展

## 快速开始

### 安装

```sh
pnpm add xadmin

```

### 使用

```js
// xadmin.js
import xd from 'xadmin'


```

```sh
node --watch xadmin.js

```
